# Fuga da Instalação

## 1. Título do jogo

**Fuga da Instalação**

## 2. Narrativa/tema

O jogador acorda dentro de uma instalação que parece ter sido abandonada depois de algum tipo de acidente. As portas estão bloqueadas e existem criaturas e sistemas de segurança espalhados pelo local.

Sem saber exatamente o que aconteceu, o jogador precisa explorar a instalação, encontrar itens e descobrir uma forma de abrir a saída antes que seja tarde demais.

## 3. Objetivo do jogo

O objetivo é explorar a instalação, encontrar os cartões e itens necessários, evitar ou enfrentar os inimigos e chegar até a saída principal para conseguir escapar.

## 4. Ações do jogador

O jogador poderá:

* Andar pelo mapa usando **W, A, S e D**.
* Mirar e atirar usando o **mouse**.
* Coletar itens andando até eles.
* Interagir com portas e objetos usando **E**.
* Abrir o menu de pausa usando **ESC**.

## 5. Inimigos e/ou obstáculos

A instalação terá inimigos que não ficarão apenas parados.

Terão criaturas ou robôs que poderão patrulhar algumas áreas e perseguir o jogador quando ele estiver próximo.

Além dos inimigos, também existirão portas bloqueadas e algumas áreas que só poderão ser acessadas depois de encontrar determinados itens.

## 6. Itens e coletáveis

Durante a exploração, o jogador poderá encontrar:

* **Cartões de acesso:** usados para abrir determinadas portas.
* **Kit de cura:** recupera parte da vida do jogador.
* **Munição:** permite continuar usando a arma.
* **Baterias:** podem ser usadas como recurso para algumas partes da instalação.

Os itens serão espalhados pelo mapa para incentivar o jogador a explorar.

## 7. Condições de vitória

O jogador vence quando conseguir encontrar os itens necessários, chegar até a saída principal e conseguir escapar da instalação.

Ao vencer, será mostrada uma tela informando que o jogador conseguiu fugir, com opções para reiniciar o jogo ou voltar ao menu.

## 8. Condições de derrota

O jogador perde quando sua vida chegar a zero.

Quando isso acontecer, será mostrada uma tela de derrota com a opção de tentar novamente ou voltar para o menu principal.

## 9. Progressão/dificuldade

A instalação será dividida em áreas que ficam mais difíceis conforme o jogador avança.

No começo, os inimigos serão mais fáceis de enfrentar, mas nas áreas mais avançadas existirão mais inimigos e obstáculos.

O jogador também precisará encontrar itens para conseguir acessar novas partes do mapa.

## 10. Referências visuais/estéticas

O jogo terá um estilo **2D top-down**, com uma aparência de instalação científica abandonada.

A ideia é usar ambientes escuros, corredores, salas de laboratório e elementos tecnológicos para criar uma atmosfera de mistério e ficção científica.

Como referência, a proposta utiliza elementos de jogos de exploração e combate em visão de cima, adaptados para um projeto simples feito na engine **Godot**.
